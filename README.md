🎬 Netflix Clone (HTML & CSS)

This project is a Netflix homepage clone built using HTML and CSS, designed to replicate the look and feel of the original Netflix landing page.

It includes a modern UI layout with trending movie sections, interactive elements, and clean styling.

🚀 Features
🎨 Modern UI Design
Inspired by Netflix homepage

Movie posters displayed in a horizontal layout
